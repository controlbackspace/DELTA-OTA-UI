6. DESKTOP MIGRATION (ELECTRON) - web app -> locally executed desktop app
   -----------------------------------------------------------------------
   MOTIVATION
   - Remove the web attack surface: no remote server, no browser sandbox
     restrictions, cryptographic work happens locally on the developer machine.

   DECISIONS (locked)
   - Dev-mode Electron only (no electron-builder installer yet).
   - Renderer wiring is ADDITIVE only: zero changes to UI/UX, components,
     or the Atomic Architecture (atoms -> molecules -> organisms -> templates).
   - Phase 4 (WalletConnect) DEFERRED until Phase A (contract deployment).
   - make_release.py was edited (approved): --json flag + version_tag sanitize.

   NEW PROJECT: desktop/ (repo root, fully separate from ui/)
   - package.json               electron dev-dep only; "main": "dist/main.js"
   - tsconfig.json              TS ~6.0.2, Node16 modules, strict, CJS emit
   - src/main.ts                COMPOSITION ROOT - app lifecycle, dependency
                                wiring, IPC handler registration only
   - src/window.ts              BrowserWindow factory (no business logic)
   - src/preload.ts             contextBridge -> window.desktopAPI (3 narrow
                                methods, no Node access exposed)
   - src/contracts/ipc.ts       channel name constants
   - src/contracts/release.ts   GeneratePatchRequest / ReleaseResult types
   - src/services/paths.ts      PURE path resolution + binary validation
   - src/services/pythonRunner.ts  PythonRunner class: spawn (hidden, no shell),
                                stdout capture, JSON parse, URL normalization
   - SOLID mapping: main = composition root (SRP); pythonRunner owns process
     lifecycle; paths.ts is pure (testable); renderer depends on the narrow
     DesktopBridge interface (Dependency Inversion); preload is the only
     Electron surface (Interface Segregation). No logic in preload/window.

   IPC CONTRACT (single source of truth: desktop/src/contracts/)
   - "patch:generate"  renderer -> main  {basePath, targetPath, versionTag}
                       -> ReleaseResult JSON parsed from python --json stdout
   - "dialog:pick-bin" renderer -> main  -> string | null (native file dialog)
   - getPathForFile(file) preload helper (webUtils) - keeps drag & drop working
   - Security: contextIsolation: true, sandbox: true, nodeIntegration: false;
     spawn with args array (shell: false) -> no command injection;
     version_tag sanitized client-side + Python-side before filename use.

   PYTHON ENGINE CHANGES (gateway/make_release.py)
   - NEW --json flag: prints a single JSON object to stdout ONLY
     {version_tag, golden_hash, patch_size, compression_ratio, patch_url,
      patch_path}; warnings/errors go to stderr.
   - NEW version_tag sanitization: [^A-Za-z0-9._-] -> "_" before it reaches
     the patch_{tag}.bin filename (path-traversal guard). Empty after
     sanitization aborts with exit code 1.
   - Human-readable terminal output is unchanged when --json is absent.

   URL NORMALIZATION (adapter at the boundary - desktop/pythonRunner.ts)
   - core.py's patch_url "http://localhost:8000/files/patch.bin" is a stale
     Phase B URL (the FastAPI server no longer exists). The desktop adapter
     rewrites it to http://local-test-server/patch_{tag}.bin - consistent with
     blockchain_poller.py's mock ipfsUrl format for Phase 3 polling.
   - mock ipfs_cid synthesized: Qm{first 8 hash hex}{tag digits} when the
     CLI does not provide one.

   RENDERER ADDITIVE WIRING (ui/secureota-ui - no visual/architecture change)
   - src/lib/desktop.ts         (NEW) DesktopBridge interface + getDesktopBridge()
                                (null in plain browser) + deriveVersionTag()
   - src/lib/utils.ts           (EDITED) + formatFileSize() helper
   - DropZone.tsx               onUpload(file) now carries the real File;
                                visuals unchanged
   - useFirmwarePipeline.ts     holds baseFile/targetFile + result state;
                                handleGenerateDelta: desktop + real files ->
                                real IPC call; desktop without files -> warning
                                log; browser -> EXACT previous simulation
   - NodeConstraintsSidebar.tsx prop plumbing only: real filenames/sizes shown
                                when files are dropped, previous fake strings
                                otherwise; golden hash / delta size / ratio now

   - DashboardScreen.tsx        passes pipeline state down; no layout/styling

   - NOTE: no fetch()/axios/api.ts exists anywhere - the "purge network

   PHASE 5 - LOCAL FILE MANAGEMENT (already satisfied, now defined)

   RUN INSTRUCTIONS (dev mode, two terminals)
   - Terminal 1 (renderer):
       cd ui/secureota-ui && npm run dev          (vite dev server on 5173)

       cd desktop && npm install && npm run build

   - Browser fallback (no Electron): pipeline runs the original simulation.

7. OFFLINE DESKTOP-IFICATION + INSTALLER
   - ui/secureota-ui/vite.config.ts (EDITED) + base: './' - the built
     index.html referenced /assets/... (root-absolute), which breaks under
     file:// and left a blank window: the ONLY working mode was the localhost
     dev server, making the app feel like "a website in a window". Relative
     paths fix offline loading entirely.
   - desktop/scripts/bundle-renderer.cjs (NEW) - runs vite build in the UI
     project, then copies dist/ -> desktop/dist/renderer/. One command builds
     the whole app: `npm run build:app` (tsc + bundle). `npm start` now loads
     the bundled UI from disk - no server, no second terminal.
   - desktop/package.json (EDITED) - scripts build:app / bundle:ui / dist;
     electron-builder config: productName SecureOTA, appId, files dist/**/*,
     extraResources ships gateway/ (minus .venv, artifacts, fixtures, pycache)
     into resources/gateway, NSIS per-user installer with dir choice.
   - desktop/src/services/pythonLocator.ts (NEW) - PythonLocator resolves the
     gateway runtime for dev AND installed layouts (strategy order: env
     SECUREOTA_GATEWAY_DIR -> resources/gateway if packaged -> repo gateway;
     python: SECUREOTA_PYTHON -> venv python.exe -> system python). Injectable
     resourcesPath for testability.
   - desktop/src/main.ts (EDITED) - uses PythonLocator; early validation with
     clear error dialogs (missing release builder / missing renderer bundle);
     VITE_DEV_SERVER_URL is now strictly an opt-in dev convenience.
   - desktop/src/services/paths.ts (EDITED) - renderer resolves to the bundled
     dist/renderer/index.html (works in dev AND inside app.asar).
   - FIXED SANDBOX BUG: sandboxed preloads cannot require() local modules, so
     preload.js failed with "module not found: ./contracts/ipc" and
     window.desktopAPI NEVER existed in the renderer (generate delta silently
     fell back to browser simulation). preload.ts now inlines the channel
     constants (comment cross-references contracts/ipc.ts as authority).
   - gateway/setup-gateway.bat (NEW) - one-shot venv + pip install, works both
     in the repo and in the installed app's resources\gateway folder.
   - desktop/build/icon.png (NEW) - generated placeholder app icon (dark bg +
     blue delta triangle); electron-builder converts to .ico for NSIS.
   - ui/secureota-ui/index.html (EDITED) - title "SecureOTA - Firmware Console"
     (window title bar).
   - .gitignore (EDITED) - + release/, + !desktop/build/icon.png.
   - README.md (EDITED) - one-command run flow, installer instructions,
     gateway runtime lookup order, packaged-mode setup, new smoke tests.
